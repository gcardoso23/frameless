Boilerplate JS

Webpack, Sass and vanilla JavaScript, with a small component pattern and nothing else to learn.

How it works

Every HTML file in app/views becomes a page. Name it with data-page on the <body> and map that name to a class in app/index.js. Each page's script is its own chunk, loaded only where it is used.

A component extends Component, names the child elements it needs with selectors and attaches its listeners. A page lists components by selector and creates one for every match, which is how this accordion is set up.

Colors, spacing and motion are CSS custom properties, so dark mode and reduced motion are just overrides. Sass covers what CSS can't do on its own: breakpoints and helper functions.

Every transition uses a duration token and an easing curve. When the system asks for reduced motion, all durations drop to zero and nothing animates.
